# Шпаргалка по LSL (Lottie Scene Language) — для LLM

## Что это такое

LSL — SQL-подобный DSL для описания 2D-анимации в LSL Studio. Пайплайн инструмента:

```
LSL-скрипт → парсер (parseDSL) → компилятор (compileToLottie) → Lottie JSON → плеер lottie-web → экспорт WebM
```

Вся сцена — это «таблица» `layers`. Анимация описывается инструкциями `UPDATE ... AT t WITH (...)`.
Язык поддерживает ровно 4 типа инструкций; любая другая конструкция вызывает ошибку компиляции
(«Неизвестная инструкция LSL»).

## Лексика и синтаксис

- Инструкции разделяются `;`. Точка с запятой внутри строковых литералов безопасна.
- Комментарии: `--` до конца строки (внутри строк не срабатывают).
- Строки — в одинарных `'...'` или двойных `"..."` кавычках; внутри можно экранировать `\'`.
- Последовательность `\n` внутри строки превращается в реальный перенос строки.
- Значения: числа (`350`, `1.2`), строки, `true`/`false`, массивы `[0.22, 1, 0.36, 1]`.
- Ключевые слова `WHERE`, `AT`, `WITH` регистронезависимы и распознаются только вне кавычек и скобок,
  поэтому строковые значения могут свободно содержать слова «where», «at» и скобки.
- Незнакомая инструкция, несовпадение числа колонок и значений в INSERT, отсутствие `id` — ошибка компиляции.

## Четыре инструкции

1. **Конфигурация** — обычно первая строка сценария:
   ```lsl
   UPDATE composition SET width = 540, height = 960, fps = 60, duration = 22.0;
   ```
   По умолчанию: 540×960 (вертикаль 9:16), 60 fps, 5.0 с.

2. **Создание слоёв** — можно несколько кортежей VALUES через запятую:
   ```lsl
   INSERT INTO layers (id, type, x, y, width, height, color, radius, opacity) VALUES
     ('wall', 'rect', 350, 480, 540, 960, '#111520', 0, 100),
     ('lamp', 'ellipse', 1200, 180, 320, 320, '#ff9d2e', 0, 12);
   ```

3. **Анимация слоёв**:
   ```lsl
   UPDATE layers SET opacity = 100 WHERE id = 'card' AT 0.5 WITH (duration = 0.6, ease = 'out');
   ```

4. **Анимация камеры** (тот же синтаксис, свойства только x, y, zoom):
   ```lsl
   UPDATE camera SET x = 1200, y = 480, zoom = 1.0 AT 4.5;
   ```

## Свойства слоя (колонки INSERT)

| Колонка | По умолчанию | Описание |
|---|---|---|
| `id` | — | Обязателен, уникален. Единственный способ адресации слоёв. |
| `type` | `'rect'` | `'rect'`, `'ellipse'` или `'text'`. |
| `x`, `y` | 0, 0 | Координаты **центра** слоя (не левого верхнего угла). |
| `width`, `height` | 100, 100 | Размер фигуры; для ellipse — диаметры по осям. |
| `radius` | 0 | Скругление углов rect (для ellipse игнорируется). Анимируемо — морфинг квадрата в круг. |
| `color` | `'#ffffff'` | HEX: `'#rrggbb'` или короткий `'#fff'`. |
| `opacity` | 100 | 0–100. |
| `rotation` | 0 | Градусы, по часовой стрелке. |
| `scale` | 100 | Проценты, применяется к обеим осям. |
| `text` | `''` | Содержимое для `type = 'text'`. |
| `size` | 24 | Размер шрифта (в пикселях композиции). |
| `font` | `'Arial'` | Название шрифта: системное или из Google Fonts. |
| `fixed` | `false` | `true` — слой не привязан к камере (HUD, плашки, затемнения). |

## Модель координат и камера

- Сцена — большой «мировой» холст, композиция — окно объектива. Камера — null-слой,
  к которому привязаны все слои с `fixed = false`.
- `zoom = 1.0` — стопроцентный масштаб; zoom умножается на 100 и идёт в scale камеры.
- Все не-fixed слои лежат в одной плоскости: параллакса нет, камера двигает всё сразу.
- Начальная позиция камеры — центр композиции. Привычка: сразу задать камеру в AT 0.0.
- `fixed = true` слои живут в координатах композиции: для 540×960 центр по X = 270,
  верхняя планка — y ≈ 35–78, нижняя — y ≈ 912–930.

## WHERE-селекторы

- `id = 'x'` — точное совпадение.
- `id IN ('a', 'b')` — список значений.
- `id LIKE 'eq_%'` — маска: `%` — любое число символов, `_` — ровно один символ,
  регистронезависимо, полное совпадение строки (`^...$`).
- Сравнения по любому столбцу: `=`, `!=`, `<>`, `>`, `<`, `>=`, `<=`.
  Сравниваются значения из INSERT (исходные), а не текущие анимированные.
- Комбинация: `OR` на верхнем уровне, `AND` внутри групп:
  `a AND b OR c` читается как `(a AND b) OR c`.
- Без WHERE обновляются все слои.

## Тайминг: AT и WITH

- `AT t` — время старта в секундах. Без `WITH (...)` — мгновенный скачок (монтажный кат).
- `WITH (duration = d, ease = ..., repeat = N, yoyo = bool, delay = d0)`.
- Реальный старт события = `AT + delay`.
- `ease`:
  - `'linear'`, `'in'`, `'out'`, `'inOut'` (по умолчанию);
  - или кастомная кривая Безье: `ease = [0.22, 1, 0.36, 1]` (формат `[x1, y1, x2, y2]`).
- `repeat = N` — всего N + 1 проходов:
  - с `yoyo = true` — маятник (чётный проход к цели, нечётный — назад);
  - без yoyo — каждый новый цикл мгновенно возвращается к стартовому значению и анимируется заново.
- Одно UPDATE меняет несколько свойств — все анимируются синхронно с одним ease.
- При совпадении времени у нескольких инструкций побеждает более поздняя.

## Что анимируется, а что нет

- **Плавно (твинится):** x и y (всегда парой), width и height (всегда парой), opacity,
  rotation, scale, color, radius, zoom камеры.
- **Мгновенно (замена по кадру):** содержимое `text`; цвет текстового слоя меняется
  в момент t без интерполяции; `size` шрифта анимировать нельзя — только задать в INSERT.
- **Сшивание каналов:** частичный SET не сбрасывает остальные свойства:
  `SET width = 330` сохраняет height, `SET x = 100` сохраняет y — трекер помнит вторую координату.

## Порядок отрисовки (z-order)

Слои рисуются в порядке, **обратном** порядку INSERT: чем позже вставлен слой,
тем выше он на экране. Первый INSERT — самый нижний (фон).

Стандартный приём «скрыт до нужного момента»: вставить слой с `opacity = 0`,
потом в нужный момент поднять до 100.

## Текст и шрифты

- `type = 'text'`, столбцы `text`, `size`, `font`.
- `font` — название из Google Fonts (подгружается автоматически при компиляции)
  или системное: Arial, Georgia, Verdana, Impact, monospace и т. п.
- Выравнивание — по центру относительно x.
- Перенос строки — `\n` внутри строкового литерала:
  `'Двойную термопасту.\nЧеловек спорил со мной о букве Ё.'`
- Смена текста через `UPDATE layers SET text = '...'` — мгновенная, в момент AT.
  Меняющаяся подпись (например, `hud_scene`) — типичный паттерн титров между сценами.

## Подводные камни

1. `id` обязателен и уникален; дубликаты не перезаписывают — создают новый слой.
2. `radius` осмыслен только для rect (для ellipse игнорируется).
3. `size` шрифта нельзя анимировать; цвет текста меняется скачком, а не плавно.
4. `repeat = 3` — это 4 прохода (повтор считается сверх первого прохода).
5. Без `WITH` значение меняется мгновенно — это и есть монтаж «в кат».
6. WHERE сравнивает с исходными значениями INSERT, а не с текущими в кадре.
7. Без AT событие происходит в t = 0 мгновенно.
8. У камеры только x, y, zoom; `width/height` для text-слоя бессмысленны.
9. Нужен перенос строки в тексте — пишите `\n`, настоящие переводы строк внутри литерала не нужны.
10. UPDATE без WHERE меняет все слои сразу — осторожно с `SET opacity`.

## Шаблон-скелет сценария

```lsl
-- 1. Конфигурация
UPDATE composition SET width = 540, height = 960, fps = 60, duration = 10.0;

-- 2. Стартовая камера
UPDATE camera SET x = 270, y = 480, zoom = 1.0 AT 0.0;

-- 3. Фон и объекты (первый INSERT — самый нижний слой)
INSERT INTO layers (id, type, x, y, width, height, color, radius, opacity) VALUES
  ('bg',   'rect',  270, 480, 540, 960, '#0f172a', 0,  100),
  ('card', 'rect',  270, 420, 300, 200, '#38bdf8',  24, 0);

-- 4. Текст
INSERT INTO layers (id, type, text, font, x, y, size, color, opacity) VALUES
  ('title', 'text', 'Привет!', 'Montserrat', 270, 300, 32, '#ffffff', 0);

-- 5. HUD с fixed = true (живёт в координатах композиции)
INSERT INTO layers (id, type, fixed, x, y, width, height, color, radius, opacity) VALUES
  ('hud_bar', 'rect', true, 270, 920, 10, 8, '#38bdf8', 4, 100);

-- 6. Таймлайн
UPDATE layers SET opacity = 100, y = 400 WHERE id = 'card' AT 0.5 WITH (duration = 0.6, ease = 'out');
UPDATE layers SET opacity = 100 WHERE id = 'title' AT 0.9 WITH (duration = 0.4, ease = 'out');
UPDATE layers SET width = 540 WHERE id = 'hud_bar' AT 0.0 WITH (duration = 10.0, ease = 'linear');
```

## Примеры по фичам

### Морфинг геометрии (rect → пилюля/круг)

```lsl
UPDATE layers SET width = 330, height = 92, radius = 22
  WHERE id = 's1_morph' AT 0.3 WITH (duration = 0.75, ease = [0.22, 1, 0.36, 1]);
```

### Массовая анимация через LIKE и OR

```lsl
-- Поднять все пять столбиков одной командой
UPDATE layers SET height = 220, y = 495, color = '#a855f7'
  WHERE id LIKE 'eq_%' AT 3.4 WITH (duration = 0.6, ease = 'inOut');

-- Акцентировать только чётные
UPDATE layers SET height = 300, y = 455, color = '#38bdf8'
  WHERE id = 'eq_2' OR id = 'eq_4' AT 4.3 WITH (duration = 0.6, ease = 'inOut');
```

### Пульс и маятник (repeat + yoyo)

```lsl
-- Квадрат вращается и надувается 4 прохода (3 повтора) туда-обратно: 0.8 c × 4 = 3.2 c
UPDATE layers SET rotation = 90, radius = 55, scale = 115
  WHERE id = 'yo_box' AT 7.0 WITH (duration = 0.8, ease = 'inOut', repeat = 3, yoyo = true);

-- Кольцо расходится и гаснет
UPDATE layers SET width = 260, height = 260, opacity = 45
  WHERE id = 'yo_ring' AT 7.0 WITH (duration = 0.8, ease = 'inOut', repeat = 3, yoyo = true);
```

### Камера: панорама, наезд, мгновенный кат

```lsl
-- Мгновенный кат на новую локацию (без WITH)
UPDATE camera SET x = 1200, y = 480, zoom = 1.0 AT 4.5;

-- Плавная панорама по залу
UPDATE camera SET x = 1220, zoom = 1.06 AT 4.6 WITH (duration = 5.5, ease = 'linear');

-- Наезд на героя крупным планом
UPDATE camera SET x = 2050, y = 450, zoom = 1.14 AT 13.8 WITH (duration = 1.2, ease = 'inOut');

-- Микро-пульс зума маятником
UPDATE camera SET zoom = 1.08 AT 7.2 WITH (duration = 1.2, ease = 'inOut', repeat = 1, yoyo = true);
```

### Реплики и сменные титры

```lsl
-- Появление облака с репликой
UPDATE layers SET opacity = 100 WHERE id IN ('bub_b1', 'txt_b1') AT 11.2 WITH (duration = 0.3, ease = 'out');
-- Исчезновение
UPDATE layers SET opacity = 0 WHERE id IN ('bub_b1', 'txt_b1') AT 13.6 WITH (duration = 0.25);

-- Смена надписи в HUD между сценами
UPDATE layers SET text = 'СЦЕНА 2 · ЗАЛ ВЕТЕРАНОВ ПРОМПТИНГА' WHERE id = 'hud_scene' AT 4.5;
```

### Финальное затемнение (fade to black)

```lsl
INSERT INTO layers (id, type, fixed, x, y, width, height, color, radius, opacity) VALUES
  ('fade_out', 'rect', true, 270, 480, 540, 960, '#000000', 0, 0);
UPDATE layers SET opacity = 100 WHERE id = 'fade_out' AT 21.0 WITH (duration = 1.0, ease = 'in');
```

### Мерцание неона (быстрый блинк)

```lsl
UPDATE layers SET opacity = 40 WHERE id = 's1_neon_txt'
  AT 0.3 WITH (duration = 0.1, repeat = 3, yoyo = true);
```

## Практический чек-лист генерации сценария

1. Начинай с `UPDATE composition` и стартовой позиции камеры.
2. Планируй сцены на широком холсте (например, локации с центрами x = 350, 1200, 2100)
   и переключайся между ними либо мгновенным катом камеры, либо плавным перелётом.
3. Вставляй «заготовки» с opacity = 0 и проявляй их по таймлайну.
4. HUD и fade-слои делай `fixed = true` с координатами композиции (центр X = width/2).
5. Следи, чтобы суммарная длительность сцены (AT + duration + repeat × duration)
   не вылезала за `duration` композиции.
6. Один логический блок = один комментарий-заголовок `--`: это удобно и человеку, и модели.
