LSL (Lottie SQL Language) — Спецификация для генерации анимаций

LSL — декларативный язык описания 2D-анимаций с синтаксисом SQL, компилируемый в Lottie JSON v5.12.2. [1]
• Все инструкции заканчиваются точкой с запятой ;.
• Комментарии начинаются с --.
• Координатная сетка: начало (0, 0) в левом верхнем углу экрана; координаты x, y задают центр любого слоя (включая прямоугольники, эллипсы и текст). [1]

1. Настройка композиции (UPDATE composition)

Задаёт параметры холста, частоту кадров и общую длительность. [1]
sql
UPDATE composition SET width = 540, height = 960, fps = 60, duration = 14.0;
Use code with caution.
• Поля: width (по умолч. 540), height (по умолч. 960), fps (по умолч. 60), duration (сек, по умолч. 5.0). [1]

2. Создание слоёв (INSERT INTO layers)

Порядок отрисовки (Z-index): чем ниже слой в коде INSERT, тем выше он на экране (слои, объявленные позже, перекрывают более ранние). [1]
sql
INSERT INTO layers (id, type, x, y, width, height, color, radius, opacity) VALUES
  ('bg',   'rect',    270, 480, 540, 960, '#0f172a', 0,  100),
  ('ball', 'ellipse', 270, 300, 80,  80,  '#38bdf8', 0,  100);

INSERT INTO layers (id, type, fixed, text, font, x, y, size, color, opacity) VALUES
  ('title', 'text', true, 'Заголовок\nВторая строка', 'Montserrat', 270, 100, 32, '#ffffff', 100);
Use code with caution.

Схема свойств слоя и значения по умолчанию:


Поле	Тип	По умолчанию	Описание
id	string	(обязательно)	Уникальный идентификатор слоя
type	string	'rect'	Тип: 'rect' (прямоугольник), 'ellipse' (эллипс), 'text' (текст)
x, y	number	0	Координаты центра слоя в пикселях
width, height	number	100	Ширина и высота (только для rect и ellipse)
radius	number	0	Скругление углов в px (только для rect)
color	string	'#ffffff'	Цвет заливки или текста в HEX (#RGB или #RRGGBB)
opacity	number	100	Непрозрачность от 0 до 100
scale	number	100	Масштаб в процентах от исходного размера (100 = 100%)
rotation	number	0	Угол поворота в градусах
fixed	boolean	false	Если true, слой приклеен к экрану (HUD) и игнорирует движение camera

font	string	'Arial'	Название семейства из Google Fonts (напр. 'Montserrat', 'JetBrains Mono', 'Playpen Sans') или системный шрифт


3. Анимация слоёв (UPDATE layers)

Изменяет свойства одного или нескольких слоёв во времени. [1]
sql
UPDATE layers
SET x = 400, opacity = 100, color = '#22c55e'
WHERE id LIKE 'item_%' AND opacity = 0
AT 1.5
WITH (duration = 0.6, delay = 0.1, ease = [0.22, 1, 0.36, 1], repeat = 2, yoyo = true);
Use code with caution.
• SET: любые свойства слоя (x, y, width, height, radius, scale, rotation, opacity, color, text). [1]
• WHERE (опционально; без него применяется ко всем слоям):
	• Операторы сравнения: =, !=, <>, >, <, >=, <=
	• Списки: id IN ('a', 'b', 'c')
	• Шаблоны: id LIKE 'prefix_%' (% — любая строка, _ — 1 символ)
	• Логика: AND, OR (приоритет у AND) [1]
• AT <сек>: время старта ключевого кадра в секундах (по умолчанию 0). [1]
• WITH (...) (опционально):
	• duration (или dur): длительность перехода в секундах. Если WITH не указан или duration = 0, происходит мгновенный скачок (кат).
	• delay: дополнительная задержка старта в секундах (суммируется с AT).
	• ease: 'linear', 'in', 'out', 'inOut' (по умолч.) или массив кривой Безье [x1, y1, x2, y2].
	• repeat: количество дополнительных повторов (0 = проиграть 1 раз, 1 = проиграть 2 раза).
	• yoyo: true / false (возврат значения обратно на чётных циклах repeat). [1]

4. Управление 2D-камерой (UPDATE camera)

Камера снимает виртуальный мир, перемещаясь по координатам (x, y) и меняя масштаб zoom. [1]
sql
-- Начальная позиция (центр экрана 540x960 = 270, 480)
UPDATE camera SET x = 270, y = 480, zoom = 1.0 AT 0.0;

-- Плавный переезд на соседнюю сцену
UPDATE camera SET x = 1000, y = 480, zoom = 1.1 AT 3.0 WITH (duration = 1.0, ease = 'inOut');

-- Мгновенный монтажный кат (без WITH)
UPDATE camera SET x = 1800, y = 480, zoom = 1.0 AT 6.0;
Use code with caution.
• Свойства: x, y (точка мира, которая окажется в центре кадра), zoom (1.0 = 100%, 1.2 = приближение, 0.8 = отдаление).
• Ограничения камеры: UPDATE camera поддерживает AT и WITH (duration, delay, ease), но не поддерживает WHERE, repeat и yoyo. [1]

5. Архитектурные правила и частые ошибки (Gotchas)

1. Единый холст для многосценовых роликов: Разносите локации по горизонтали (например, Сцена 1 на x = 350, Сцена 2 на x = 1100, Сцена 3 на x = 1850) и переключайтесь между ними через UPDATE camera. [1]
2. Не анимируйте size и font текста: В движке анимируются только text и color текстового слоя (через дискретные кадры), а размер шрифта size статичен — для увеличения текста используйте scale. [1]
3. Учитывайте ширину облачков под текст: Текст не переносится автоматически по ширине контейнера — расставляйте \n вручную и делайте подложку (rect) с запасом по width и height. [1]
4. Не перекрывайте AT на одном канале одного слоя: Два UPDATE на одно и то же свойство (например, x и y делят общий канал позиции, а width и height — общий канал размера) не должны пересекаться по времени. [1]
